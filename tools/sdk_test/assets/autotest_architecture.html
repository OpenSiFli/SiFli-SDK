尚未收敛

QEMU 控制台没有走中断

已实测：使能 UART 接收中断、把所有向量都指向探针、放开全部 32 条 NVIC 线， 没有任何设备中断产生。控制台是轮询的，所以别拿它验证中断相关行为。

lz4 的 boundaries 断言失败

第一次真正被执行到。它期望 LZ4_decompress_safe(..., dstCapacity=4) 在解出 1024 字节时返回负值，实测返回 +1024。 LZ4 头文件的契约明说这种情况要返回负的错误码。未定论是测试写错还是这份 lz4 的容量检查有缺口——没有为了让套件变绿而弱化断言。

打桩用例未交付

CMock 基建（源码、生成配置、示例 mock、Ruby）都就位了，缺的是用例本身。 目标要选中间件级函数而不是 HAL 函数：两个非板卡载体都没有芯片， bf0_hal_*.h 依赖只有芯片才有的头文件，编不过。

真板卡端到端未在硬件上跑过

代码路径就绪、有端到端自测覆盖（真 Lab Agent + 伪造设备），但没上过真板子。 QEMU 那条链路已经实测通过。
