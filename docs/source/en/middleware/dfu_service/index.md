# Firmware Upgrade Service

Device Firmware Update (DFU) is the process of downloading target firmware to a
device and replacing the currently running firmware, thereby completing the
device's firmware version upgrade. Typically, devices can download upgrade
firmware via serial port or Over-the-Air (OTA) methods. SiFli firmware upgrade
service supports downloading upgrade firmware via BLE.
