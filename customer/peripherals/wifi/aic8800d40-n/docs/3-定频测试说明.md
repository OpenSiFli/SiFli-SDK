# 定频测试说明

## 1. 概述与命令链路

定频测试（RF Test）用于产测校准：发射功率/EVM/频偏测量、接收灵敏度统计、efuse 读写等。

命令链路：

```
iwpriv aicrftest <cmd> <args>
        │
        ▼  wifi_port_cmd.c (仅 WIFI_MODE_RFTEST 模式下放行)
aic_cli_run_cmd()  ──►  Cli_RunCmd() 入队 ──►  cli_cmd_task
        │
        ▼  cli_cmd.c
handle_private_cmd() ──► aic_priv_commands[] 命令表匹配 ──► rwnx_send_rftest_req()
        │
        ▼
DBG_RFTEST_REQ 消息下发固件执行，结果经 CliPrint → ATRESP 回传
```

要点：

- `aicrftest` 子命令**仅在 RFTEST 模式下生效**，其他模式回 `rf bin is not exist or not in productmode!!!`
- 子命令匹配**大小写不敏感、支持前缀匹配**（前缀歧义时列出候选，如 `set_`）
- 参数解析支持 `0x` 十六进制前缀与负数；命令回显以 `[aicCli]:` 开头、`*aic` 结尾

## 2. 驱动如何配置（进入定频模式）

### 2.1 编译期：加入 RF 测试固件

`platform_config.mk`：

```make
AIC_WIFI_MODE_RFTEST ?= 1      # 默认 0；置 1 时自动加 -DCONFIG_WIFI_MODE_RFTEST
```

innermode（`CONFIG_LOAD_FW=2`，固件内嵌数组）下，该开关会把对应芯片的 RF 固件数组编进固件包：

| 芯片 | RF 固件数组 | 探测枚举 |
| ---- | ----------- | -------- |
| AIC8801 | `fw/fmacfw_rf.h` | `FMACFW_RF` |
| DC/DW | `fw/lmacfw_rf_8800dc.h` | `LMACFW_RF_8800DC` |
| D80 (含 H 版) | `fw/lmacfw_rf_8800d80_u02.h` | `FMACFW_RF_8800D80_U02` |
| D80N | `fw/lmacfw_rf_8800d80n.h` | `LMACFW_RF_8800D80N` |

### 2.2 运行时：切换到 RFTEST 模式

```
iwpriv switch test
```

执行流程：

1. `aicwf_rftest_fw_available()` 先探测 RF 固件是否存在：
   - innermode：检查上表对应固件数组非空
   - flashmode：复用 fw_type 位探测；filemode 无探测机制，返回不可用
2. 不存在 → 回 `rf bin is not exist!!!`；存在 → `wifi_set_mode(WIFI_MODE_RFTEST)` + `wifi_driver_action(0x03)`（芯片掉电+上电+重载驱动，约 2~3s 生效）
3. 重载时走 rftest 加载分支：只加载 RF 固件本体，**不执行** calib/patch 流程

回到正常业务模式：`iwpriv switch sta` 或 `iwpriv switch ap`。

### 2.3 指令入口格式

文档/产测工具中常见的 linux 格式：

```
wifi_test wlan0 set_tx chan bw mode rate length
```

本驱动等价形式（`wifi_test wlan0` 即前缀占位符 `iwpriv`）：

```
iwpriv aicrftest set_tx chan bw mode rate length
```

其余指令按同样方式转换即可。

## 3. 命令明细

### 3.1 发射类

| 命令 | 格式 | 说明 |
| ---- | ---- | ---- |
| `set_tx` | `<chan> <bw> <mode> <rate> <length> [interval]` | 连续发包。bw: 0=20M/1=40M；mode: 0=legacy/2=HT/4=VHT/5=HE_SU；rate: 速率索引 (legacy 0~11 / MCS)；length: 包长字节；interval: 发包间隔 us，缺省 10000 |
| `set_txstop` | - | 停止发包 |
| `set_txtone` | `<val> [freq]` | 单载波 (tone)。val: 0=off；freq: 频偏量 |
| `set_power` | `<val>` | 发射功率。8801: `(ana<<4)\|dig` 双 nibble (hex)；其他芯片: 单值十进制，上限 0x1e |
| `set_ant` | `<val>` | 天线选择：0=ant0 / 1=ant1 / 2=both（D80X2 双天线） |
| `set_papr` | `<val>` | PAPR 滤波，优化边带抑制 |
| `set_notch` | `<val>` | notch 滤波，优化边带抑制 |
| `set_srrc` | `<val>` | SRRC 边带抑制使能/关闭 |
| `set_fss` | `<val>` | 杂散/毛刺抑制使能/关闭 |

用例（2.4G ch6 HT MCS7 20M 1024 字节连发，测 EVM）：

```
iwpriv aicrftest set_tx 6 0 2 7 1024
[aicCli]:SET_TX
[aicCli]:txparam:6,0,2,7,1024,10000*aic
...
iwpriv aicrftest set_txstop
```

5G ch36 VHT MCS9 80M 等按上表替换参数即可。

### 3.2 接收类

| 命令 | 格式 | 说明 |
| ---- | ---- | ---- |
| `set_rx` | `<chan> <bw>` | 进入连续收包统计 |
| `get_rx_result` | - | 查询收包统计：fcsok / total |
| `set_rxstop` | - | 停止收包 |
| `set_rx_meter` | `<val>` | RX meter 测量 |

用例（灵敏度测试：综测仪打标准包后统计 PER）：

```
iwpriv aicrftest set_rx 6 0
iwpriv aicrftest get_rx_result
[aicCli]:done: getrx fcsok=9981, total=10000*aic    ← PER ≈ 0.19%
iwpriv aicrftest set_rxstop
```

### 3.3 频偏 / 晶振校准

| 命令 | 格式 | 说明 |
| ---- | ---- | ---- |
| `set_xtal_cap` | `<val>` (0~31) | 设置晶振粗调 cap，回显调节前后值 |
| `set_xtal_cap_fine` | `<val>` (0~63) | 晶振细调 cap |
| `set_freq_cal` | `<hex val>` | 频偏校准字写入 |
| `set_freq_cal_fine` | `<hex val>` | 频偏细调校准字 |
| `get_freq_cal` | - | 读取当前 cap/cap_fine 及 remain |
| `set_cal_xtal` | - | 启动一次晶振自动校准 |
| `get_cal_xtal_res` | - | 读取自动校准结果 (cap & cap_fine) |
| `set_cob_cal` | `<dutid> <chip_num> <disxtal>` | DUT-Golden 组网校准 |
| `get_cob_cal_res` | - | 读取组网校准结果（cap/freq_ofst/双向 RSSI/SNR） |
| `do_cob_test` | `[disxtal]` | 一键组网校准 (内置 2s 等待) |

用例（频偏校准）：

```
iwpriv aicrftest get_freq_cal
[aicCli]:cap=0x1e (remain:3), cap_fine=20 (remain:0)*aic
iwpriv aicrftest set_xtal_cap 30
[aicCli]:done: xtal cap: 0x1e -> 0x1e*aic
```

### 3.4 efuse / MAC 读写

| 命令 | 格式 | 说明 |
| ---- | ---- | ---- |
| `get_efuse_block` | `<block>` | 读取指定 efuse block (hex) |
| `set_mac_addr` | `<b5> <b4> <b3> <b2> <b1> <b0>` (hex) | 写 WiFi MAC，**最多写 2 次** |
| `get_mac_addr` | - | 读 WiFi MAC (DC/DW 附带剩余可写次数) |
| `set_bt_mac_addr` | 同上 | 写 BT MAC，**最多写 2 次** |
| `get_bt_mac_addr` | - | 读 BT MAC |
| `set_vendor_info` | `<hex val>` | 写厂商信息，**仅允许写 1 次** |
| `get_vendor_info` | - | 读厂商信息 |
| `rdwr_efuse_usrdata` | `[func] [cnt] [w0 w1 w2]` | 用户自定义区读写 (func 0=读, 1=写, 共 3 word) |
| `rdwr_efuse_sdiocfg` | `<func> [val]` | SDIO 配置位读写 (func 0=读, 1=写) |
| `rdwr_efuse_usbvidpid` | `<func> [vidpid_hex]` | USB VID/PID 读写 (func 0=读, 1=写) |
| `rdwr_efuse_he_off` | `<0/1>` | efuse HE 关闭位 |

用例（产测写 MAC）：

```
iwpriv aicrftest set_mac_addr aa 69 55 33 00 88
[aicCli]:set macaddr:aa,69,55,33,0,88*aic
iwpriv aicrftest get_mac_addr
[aicCli]:done: 0x695533008 0x88 (remain:1)*aic
```

### 3.5 功率表校准

| 命令 | 格式 | 说明 |
| ---- | ---- | ---- |
| `rdwr_pwrmm` | `[val]` | 功率手动模式开关 (0=走 pwrlvl 表, 1=走 set_power) |
| `rdwr_pwrlvl` | `<band> <grp> [idx] [lvl]` / `<band> <grp> <lvl x N>` | 功率等级表读写。band: 1=2.4g/2=5g；grp: 0=11b+11a/g, 1=11n/11ac, 2=11ax；单点写 `band grp idx lvl`，整组写 `band grp lvl1..lvlN` (grp1 共 10 项，其余 12 项)。**8801 不支持** |
| `rdwr_pwridx` | `<band> <mod> <idx>` | 功率索引表读写 (仅 8801) |
| `rdwr_pwrofst` | 见下 | 功率偏移读写。D80/D80N: `<band> <rate> <chgrp> <ofst>`；DC/DW/8801: `<band> <chgrp> <ofst>`。chgrp 2.4g: 0=ch1~4/1=ch5~9/2=ch10~13；5g: 0=ch36~64/1=ch100~120/2=ch122~140/3=ch142~165 |
| `rdwr_pwrofstfine` | `<band> <chgrp> <ofstfine>` | 功率细调偏移 |
| `rdwr_drvibit` | `<func> [ibit]` | PA drv_ibit 读写 (func 0=读, 1=写) |
| `rdwr_efuse_pwrofst` | 同 rdwr_pwrofst | efuse 功率偏移，**最多写 2 次** |
| `rdwr_efuse_pwrofstfine` | `<band> <chgrp> <ofstfine>` | efuse 功率细调偏移 |
| `rdwr_efuse_drvibit` | `<func> [ibit]` | efuse PA drv_ibit，**仅允许写 1 次** |

用例（2.4G ch5~9 组 11ax 功率等级单点改写后回读）：

```
iwpriv aicrftest rdwr_pwrmm 1          ; 先切手动模式
iwpriv aicrftest set_power 20
iwpriv aicrftest rdwr_pwrlvl 1 2 5 18  ; 2.4g/11ax/[5]=18
iwpriv aicrftest rdwr_pwrlvl 0         ; 回读整表
```

## 4. 典型产测流程示例

```
; ① 切定频模式
iwpriv switch test                     ; 等待 2~3s

; ② 发射功率/EVM 测试
iwpriv aicrftest set_tx 6 0 2 7 1024   ; ch6 HT MCS7 20M
iwpriv aicrftest set_power 24          ; 目标功率
...综测仪测量，逐档调整...
iwpriv aicrftest set_txstop

; ③ 频偏校准
iwpriv aicrftest set_tx 6 0 2 7 1024
iwpriv aicrftest set_xtal_cap 30       ; 按综测仪读数微调
iwpriv aicrftest get_freq_cal          ; 确认结果
iwpriv aicrftest set_txstop

; ④ 接收灵敏度
iwpriv aicrftest set_rx 6 0            ; 综测仪打包
iwpriv aicrftest get_rx_result         ; 统计 PER
iwpriv aicrftest set_rxstop

; ⑤ 写号 (MAC/vendor/功率表 efuse)，见 3.4/3.5

; ⑥ 回业务模式
iwpriv switch sta
```

> 注意：efuse 写入均有次数限制（MAC 2 次、vendor 1 次等），产测治具需先 `get_*` 确认剩余次数再写。
